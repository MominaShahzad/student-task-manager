# Student Task Manager

## Project Description
A simple web app to add, display, complete, delete, and search tasks. Built as a Git & GitHub collaborative assignment.

## Team Members
- Momina Shahzad (Student 1)
- Eman Manzoor (Student 2)

## Features
- Add tasks with title and description
- Styled, responsive layout
- Search tasks by title

## Technologies
HTML, CSS, JavaScript, Git, GitHub
